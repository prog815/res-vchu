# Реестр РЭС и ВЧУ, разрешённых для ввоза на территорию РФ

Онлайн-справочник по официальному набору открытых данных «Реестр РЭС и ВЧУ разрешенных для ввоза на территорию Российской Федерации», ведомому Федеральной службой по надзору в сфере связи, информационных технологий и массовых коммуникаций (Роскомнадзор).

🌐 Сайт: https://prog815.github.io/res-vchu/

Справочник бесплатный, без регистрации и установки. Работает прямо в браузере — на компьютере и на телефоне. Данные берутся из официального открытого набора и обновляются автоматически.

---

## Что это за реестр

Это официальный машиночитаемый перечень **радиоэлектронных средств и высокочастотных устройств (РЭС и ВЧУ)**, разрешённых для ввоза на территорию Российской Федерации.

**Одна запись здесь — это одна позиция реестра** (конкретная модель устройства), а не событие выдачи. В текущем снимке справочника содержится **14 380 записей**.

Каждая запись содержит следующие данные:
- **Модель** (основной идентификатор устройства).
- **Тип РЭС или ВЧУ** (например, Радиостанция, Базовая станция, Радиомикрофон и т.д.).
- **Изготовитель** (наименование производителя).
- **Страна** (страна изготовителя, может быть несколько).
- **Реестровый номер** записи.
- **Срок действия** реестровой записи.
- **Статус** (Действует / Исключена).
- **Примечание** (дополнительная информация, например, о ввозе без лицензии Минпромторга).

Справочник поможет быстро проверить, разрешён ли ввоз конкретного устройства, найти его реестровый номер, уточнить статус действия разрешения и данные изготовителя.

## Для кого и зачем

- **Импортёры и участники ВЭД** — проверка legality ввоза оборудования и наличия разрешения.
- **Таможенные представители и брокеры** — сверка моделей и реестровых номеров при декларировании.
- **Производители электроники и IT-компании** — анализ представленности брендов и актуальности сертификации.
- **Юристы и комплаенс** — оценка рисков при закупке радиоэлектронного оборудования.
- **Службы безопасности и тендерные отделы** — проверка подрядчиков и поставляемого оборудования.

## Как пользоваться

### Поиск

Введите в строку поиска одно или несколько слов. Справочник ищет совпадения по:
- модели устройства;
- типу РЭС/ВЧУ;
- изготовителю;
- стране происхождения;
- реестровому номеру;
- примечанию.

Если ввести несколько слов, система найдёт записи, где встречаются **все** введённые слова (в любом порядке). Регистр букв не важен, а буквы `Ё` и `Е` считаются одинаковыми.

### Фильтры

В интерфейсе оставлен **только один выпадающий список**:
- **Статус записи**: позволяет отфильтровать записи по статусу (`isActual_label`): Действует, Исключена.

### Карточка результата

Каждая найденная запись оформлена в виде карточки:
- **Заголовок** — модель устройства (или тип, если модель не указана).
- **Бейджи** — статус (зелёный — действует, серый — исключена), тип устройства (синий) и метка «Срок истёк» (оранжевый), если применимо.
- **Основные реквизиты** — реестровый номер и срок действия.
- **Блок «Изготовитель»** — наименование производителя.
- **Блок «Страна»** — страна происхождения.
- **Блок «Примечание»** — дополнительная информация.
- Кнопка **«📋 строка»** — копирует все 14 полей (включая скрытый ID и служебные поля) в виде одной строки (удобно для вставки в Excel).
- Кнопка **«📤 Поделиться»** — позволяет отправить подробную текстовую карточку со ссылкой на конкретную запись.

> **Примечание:** В исходном наборе присутствует статус записи и срок действия. Поле «срок действия» является датой окончания, но исключение из реестра может произойти раньше. Уникальный идентификатор записи (ID) не отображается в интерфейсе, но используется для стабильной работы ссылок «Поделиться».

### Навигация

- Результаты показываются порциями по 20 штук; кнопка **«Показать ещё»** догружает следующие карточки.
- Счётчик вверху экрана показывает, сколько всего записей найдено и сколько из них уже выведено.
- Плавающие кнопки **↑ / ↓** в правом нижнем углу помогают быстро прокрутить страницу.
- Ссылка **«Очистить»** сбрасывает поисковый запрос и выбранные фильтры.
- При загрузке данных отображается анимированный индикатор. Файл с данными весит около **620 КБ** и загружается за 1–2 секунды.

## Что внутри справочника

В справочнике собраны данные обо всех записях, включённых в текущий снимок набора данных Роскомнадзора.

Точная статистика по количеству записей и дата актуальности данных всегда показаны **внизу страницы** на самом сайте. Они рассчитываются автоматически на основе загруженных данных.

Данные обновляются из источника автоматически (раз в неделю по воскресеньям). Дата актуальности текущей версии видна **внизу страницы**.

## Ограничения и дисклеймер

- Справочник носит исключительно **информационный характер**. Для официального применения (таможенное оформление, юридические заключения) сверяйтесь с действующими государственными реестрами или официальным сайтом Роскомнадзора.
- В исходном наборе **отсутствуют ИНН, ОГРН и КПП**. Идентификация изготовителей возможна только по наименованию.
- Поле «Наименование товара» (`productName`) в исходных данных часто пустое, поэтому основным идентификатором выступает «Модель» (`model`).
- Все элементы интерфейса (бейджи, кнопки) добавлены на стороне справочника для удобства пользователей и не являются частью официального источника.
